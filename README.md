This project investigates the **AEX** stock index for the course Mathematical Statistics 1 using R.

The completed analysis covers exploratory data analysis, statistical modelling and inference for daily returns in 2005 and 2020 and prediction of yearly average daily returns. The final report discusses the methods, findings, assumptions, and limitations.

## Import and data checks

Run the following commands from the project root in RStudio.

### Import and data validation

```r
source("Import.R")
```

This script:

- Lists the available data files.
- Displays the first lines of the CSV file.

- Converts the date column to R's `Date` type.
- Sorts observations chronologically.
- Checks column types and the date range.

## Dataset

The historical dataset contains 7,660 observations from 2 January 1995 to 31 December 2024.

Available columns:

| Column | Description |
|--------|-------------|
| `Date` | Trading date |
| `Open` | Opening index value |
| `High` | Highest index value during the day |
| `Low` | Lowest index value during the day |
| `Close` | Closing index value |
| `Volume` | Volume field supplied in the dataset |
| `Change` | Percentage change in the closing value relative to the previous day |

The historical data contain no missing values or duplicated dates. The `Volume` field equals zero on 5,852 days and is not used in the analysis.

The separate 2025 dataset contains 255 trading days. These observations are used only to evaluate the final forecast, not to fit or select the models.

## Analysis

### Exploratory data analysis

```r
source("Exploratory_data_analysis.R")
```

The exploratory analysis examines:

- Opening and closing index values from 1995 to 2024.
- Daily returns and descriptive statistics.
- The plausibility of treating observations as independent and identically distributed.
- The saying “Sell in May and go away”, considering returns until September and November.
- The relationship between January returns and returns over the remainder of the year.

### Statistical modelling and basic inference

For 2005 and 2020, the report presents:

- Histograms and normal QQ plots.
- Normal and location-scale Student's t models.
- Maximum likelihood parameter estimates.
- Model comparison using AIC.
- Two-sided 95% confidence intervals for the expected daily return.
- Two-sided tests for a nonzero expected daily return.
- One-sided tests for a positive expected daily return.

### Estimating and predicting yearly average daily returns

After importing the historical data, run:

```r
source("Estimating_and_predicting_yearly_average_returns.R")
```

This script:

- Calculates yearly average daily returns.
- Fits constant-mean and linear-trend models.
- Evaluates one-year-ahead forecasts for 2010–2024 using an expanding training window.
- Compares the models using mean squared prediction error.
- Predicts the 2025 average daily return and constructs a 95% prediction interval.
- Produces residual diagnostic plots.
- Imports the separate 2025 dataset and compares the observed average with the forecast.
- Saves figures and numerical results.

The script requires the `aex` data frame and the file `data/AEX Historical Data 2025.csv`.

***
## Main Findings

- Daily returns fluctuate around zero, with extreme observations and changing volatility.
- An i.i.d. model is not considered plausible for the full historical period.
- The seasonal analyses do not consistently support either market saying.
- A normal model provides a reasonable approximation for 2005, while a Student's t model better describes the heavy tails in 2020.
- At the 5% significance level, the tests provide evidence of a positive expected daily return in 2005. For 2020, there is insufficient evidence of a nonzero or positive expected return.
- The constant-mean model achieves a lower historical prediction MSE than the linear-trend model.

***

## Limitations

The statistical procedures rely on modelling assumptions, including independence, normality and constant variance where applicable.

Heavy tails and changing volatility make these assumptions questionable, particularly for 2020. The yearly-model residual diagnostics also indicate departures from normality. Consequently, the nominal coverage of the confidence and prediction intervals is not guaranteed.
